## 流程

```text
输入规范化
→ 引用/上下文解析
→ 按参与者身份/类型/物态产生结构性绑定候选
→ 有类型谓词计算，含有界精确/动态目标 Relation（TRUE/FALSE/UNKNOWN）
→ 阻断条件
→ 适用规则消解图
→ 关系/物种组成/精确实体离子源解析
→ 有类型产物构造
→ 规范实体解析
→ 精确配平
→ 原子校验
→ 电荷校验
→ 按参与者签名查找规范 Reaction
→ 必需条件兼容性筛选
→ ReactionCandidate + 证明轨迹
```

只有在可观察结果和证明语义仍确定时，实现才可短路。

## 匹配与 UNKNOWN

参与者绑定使用规范身份/类型/物态约束。仅限水溶液的家族要求试剂为 aqueous；M10 还要求金属为 solid。仅有水溶液介质不能自动溶解输入或转换物态。必需/禁止 Facet 和上下文条件使用有类型谓词注册表。多个绑定按确定方式计算，某个任意绑定失败不能压制另一有效绑定。

缺失/开放世界知识为 `UNKNOWN`，不是 false。显式 `unknown`、`not_applicable` 和缺失事实在轨迹中仍可区分。

Relation 谓词解析 `(源绑定, 受控关系键, 规范目标 ID, 上下文)`，目标可为精确 ID 或来自有类型实体源。M19 可从所绑定盐的上下文匹配规范物种组成中选择唯一阳离子。有证据的匹配断言为已知真；无断言或目标源不可用/歧义为 ABSENT/UNKNOWN。只接受 `equals expected: true`。同一目标、相同具体程度的断言确定性合并证据；只有最终适用绑定的断言进入候选来源。

## 规则消解

选择赢家前考虑所有完全适用规则。`overrides`、`specializes`、`fallback_for` 显式定义优先关系，且尊重其传递性。被阻断路径不能压制独立 UNKNOWN 路径；没有完全适用规则时，该结果仍为 indeterminate。多个非等价赢家保留时返回结构化 `ambiguous_rule_resolution`，不能按源顺序选取。

声明 `mutually_exclusive_with` 的两条规则若同时适用，会违反源数据的互斥假设，形成运行时歧义。

## 产物构造与校验

产物只通过有界规范构造器解析。离子对构造使用规范离子的电荷/组成及精确正整数系数，必须解析到一个已有中性 Substance。无法解析或存在歧义都显式报告，不能虚构 Entity。

离子对构造使用绑定的水溶液反应物时，候选及 `products.constructed` 证明事件保留所用物种组成配置的规范化键、模型、目标和证据 ID。使用单跳关系目标时，另行保留源 ID、关系键、目标 ID、规范化上下文和证据 ID。关系目标构造在过滤负断言前检查相同具体程度的 TRUE/FALSE 矛盾。未使用 Relation 的候选不输出关系来源。这些确定性元数据不产生第二套化学事实。

M10 用此边界组合“单质金属 → 产物阳离子”与“酸 → 解离阴离子”。固体金属不获得虚假水溶液物种组成；编译器不猜氧化态或化合价。缺失/歧义关系目标在配平前产生结构化诊断。

M11 复用金属阳离子关系路径，以精确规范离子源解析 OH-，不把该固定离子归因于水的解离。固体金属/液态水物态约束先于谓词检查；`metal.water_reactivity` 是独立常温上下文事实，M10 相对氢活动性不能使 Zn/Mg 成为常温水正例。缺失反应性为 UNKNOWN；Rule 其他条件适用后，缺失阳离子关系或精确离子目标成为显式解析失败。

M19 用一个通用 Rule 表达水溶液金属盐置换。盐的规范物种组成把唯一阳离子提供给动态 `metal.displaces_cation` 谓词，把阴离子提供给产物构造；独立 `metal.product_cation` 给出加入金属的阳离子，既有离子对解析器选择中性规范盐。被置换阳离子经恰好一次 `ion.elemental_substance` 关系到达其单质金属 Substance。CuSO4、AgNO3、CuCl2 因而复用同一家族，不涉及活动性排序、化学式解析、反向推断、化合价猜测或产物虚构。

M20 为同一单跳关系提供三种结果：适用正断言为 TRUE，适用 `truth: false` 为 FALSE，无断言为 UNKNOWN。FALSE 置换谓词只排除该 M19 绑定/路径，不形成规范负面 Reaction 或全局“不反应”。动态阳离子解析和否定断言证据均在轨迹中可见。

`EntitySourcePlan` 仅有四种形式：精确实体、参与者绑定、唯一指定电荷符号的解离离子，以及源自身不能是 Relation 目标的单跳关系目标。解析保留所用配置/断言/证据。缺失或歧义的物种组成、产物阳离子、离子到单质映射产生结构化不确定/解析诊断，绝不创建目标。

配平接收固定规范反应物/产物并使用精确算术。M6 碳酸盐家族说明：产物身份确定后，多质子分子化学计量由规范组成推得，Rule 或引擎分支不提供系数。原子与电荷校验是独立阶段和诊断。

## 规范比较

规范比较在验证后进行。规范化参与者签名合并相同角色/实体/物态项，将精确有理数系数约为最简整数，再查找化学匹配；各规范 Reaction 的嵌入条件作为必需键值约束。兼容性忽略候选额外上下文，但缺失/冲突的必需条件会排除该匹配。`none`、单一精确匹配和多匹配冲突可区分。条件证据和兼容性决定保留在证明/来源中。即使精确匹配也仍是生成的 ReactionCandidate，只有单独整理审核才改变规范源数据。

## ReactionForm 投影

只有声明的 `required_assumptions` 和唯一上下文匹配规范物种组成可用时，才投影 ReactionForm。响应保留所属 `reaction_id`、精确系数、原子/电荷校验、推导算子、Reaction 条件和证据；不创建新 Reaction。消去旁观离子后，净离子参与者约到最小精确有理数比例。

M7 仍只覆盖有界强电解质水溶液投影。铵盐/碱家族仅在 aqueous warmed 上下文输出 `NH3(g)`。缺失/歧义物种组成显式报告；这不是通用水溶液物种求解器、氨平衡模型或相对酸强度模型。

某家族谓词已知为 false 时，另一结构上可能的家族仍可能依赖缺失知识，因此整体可为 `indeterminate/unknown_applicability`。这不生成候选，也不编写规范负面反应事实。

## 结构化诊断

运行时/源数据失败使用确定性对象，包含 `code`、`stage`、`message` 和可选详情。当前区分：

`schema_invalid`、`reference_unresolved`、`unknown_applicability`、`blocked`、`no_rule_match`、`ambiguous_rule_resolution`、`rule_overlap_compile_error`、`product_unresolved`、`balance_failure`、`atom_validation_failure`、`charge_validation_failure`、`canonical_no_match`、`canonical_conflict`。

## 证明轨迹

轨迹事件保留规范化输入、规则 ID/版本、谓词算子/主体/键/目标/期望值、真值、知识状态、事实来源、匹配关系断言及证据、阻断检查、规则消解、物种组成/关系产物输入、配平、守恒校验、规范比较和输出候选键。
