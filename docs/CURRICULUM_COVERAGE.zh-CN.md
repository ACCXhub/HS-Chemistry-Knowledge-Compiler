# 大陆高中课程覆盖与缺口

[English](CURRICULUM_COVERAGE.md)

验收目标为普通高中必修＋选择性必修。**目前尚未覆盖所需全部方程式，也不能由元素标签推出任意正确反应。** 下表是按常见教学主题整理的工程验收清单，不是教育部或某版教材发布的逐条方程目录，不能据此宣称教材全覆盖。

当前 102 条规范 Reaction、27 条 Rule、159 个案例。103 个案例生成方程，覆盖全部 102 条规范 Reaction，另含 1 条未存储方程。剩余案例为 43 个 indeterminate、12 个 no_match、1 个 blocked。这些边界结果不算方程覆盖。

## 未存储方程如何推导

运行顺序是“实体分类/物态 → 上下文属性或单跳 Relation → 选择规则 → 解析已有规范产物 → 精确配平 → 原子/电荷校验 → 对照已有 Reaction”。最后一步只查重/比对，不能决定前面是否生成。

本轮验证移除全部 Reaction 记录后重编译，27 条规则仍生成全部 103 个正例，参与者和 candidate_key 不变，规范匹配变为 none。新增 HBr 的非氧化性酸证据后，复用 M9 得到未存储的 `2 HBr + Na2S2O3 → 2 NaBr + SO2 + S + H2O`，不新增这条 Reaction。

因此新增一种物质时，若其规范身份/组成、分类、必要上下文属性、解离或 Relation、候选产物身份和证据齐全，已有规则可支持新组合。仅添加“活泼金属”“氧化剂”标签不足以决定价态、选择性或实际产物；守恒成立也不是反应可发生的充分条件。

## 后续验收顺序

1. 课程补齐已持续进行，下一验收重点为**教材逐式目录与差距核验**。按选定教材章节冻结一份有限逐式清单，先填酸/碱/氧化物和 Fe/Al 等常见无机缺口；每条记录附来源、条件、正例与必要反例。
2. 浓度、过量、催化、可逆和电极式先确定最小必要语义，再填含这些条件的反应；不能把条件藏在备注中却当普通反应匹配。
3. 有机与选择性必修剩余主题分批验收。指标分开记录 canonical 数、可推断数、明确边界数；氧化物、亚铁和铜硝酸盐批次已实现，表中缺失家族仍待补。
