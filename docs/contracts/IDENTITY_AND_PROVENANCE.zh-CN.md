# 身份与溯源

[English](IDENTITY_AND_PROVENANCE.md)

> 中文版对应英文文档；历史章节保留其当时范围与版本。后续契约变更须同步维护两种语言。

状态：**F1 规范原则**

## 1. 身份规则

稳定身份独立于名称、别名、化学式显示、分类、课程路径、文件路径、YAML 顺序和运行时表示。

仅当对象/断言具有独立生命周期或需要持久外部引用时，才使用不承载含义的持久 ID。

## 2. 语义键

语义键支持查找、对照、验证和迁移，不替代永久身份。例如原子序数、元素符号、经整理的登记键和规范化记法键。

## 3. 溯源

整理审核的知识记录按其生命周期携带证据和整理历史。推导/生成输出携带源修订、规则身份/版本、输入、验证结果和编译器修订等推导来源。

## 4. 候选溯源

确定性候选键是生成语义身份的一部分，可由规范语义内容和声明的推导输入重现。

持久审核 ID 标识审核流程对象，不标识纯编译输出。

## 5. 迁移

旧 ID 和路径只作为迁移别名。迁移可把多个旧记录合为一个规范记录，也可把混淆的旧记录拆成多个规范身份。旧 schema 字段不必作为永久规范字段保留。

迁移层只负责持久的旧身份到规范身份映射，或显式有界处置：`mapped_existing`、`created_canonical`、`skipped_unsupported`、`ambiguous`、`rejected_invalid`。化学式、名称和旧路径可定位候选，但不能代替指称层次、类型、组成、电荷、符号、原子序数等适用校验来确定身份。歧义不得按记录或文件顺序选出赢家。

创建规范数据始终是单独的、经过证据检查的源数据整理操作。旧 `reviewed` 状态、合并产物就绪状态、编辑性来源和待验证目标均不构成权威证据。迁移状态不进入 Entity 别名、Rule DSL 或编译推断产物。

`migration/legacy_identity.py` 是离线身份对照和确定性映射生成的唯一规范实现。里程碑专用样本清单和不可变报告可独立保存；兼容入口必须委托该实现，不能另写一套匹配语义。
